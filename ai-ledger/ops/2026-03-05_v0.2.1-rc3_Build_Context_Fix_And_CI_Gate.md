## Background

RC2 deployment revealed that `seed_demo_data.py` was missing from the Docker container. The script existed at repo root `scripts/seed_demo_data.py` but the Docker build context (`./backend`) did not include it.

Human Tester confirmed 401 errors because the database was empty and no seed data existed.

---

## Issue A — Build Context Mismatch

### Root Cause

```
repo root/
├── backend/           ← Docker build context
│   ├── Dockerfile
│   └── ...            ← These go to /app in container
├── scripts/
│   └── seed_demo_data.py   ← NEVER copied to container!
└── ...
```

The `docker-compose.prod.yml` specified `context: ./backend`, so only files in the `backend/` directory were copied into the image.

### Fix

Moved entire `scripts/` directory into `backend/scripts/`:

```bash
mv scripts/ backend/scripts/
```

This ensures all seed scripts are included in the Docker build context.

---

## Issue B — Missing PYTHONPATH

### Symptom

```
ModuleNotFoundError: No module named 'database'
```

### Fix

Added `PYTHONPATH=/app` to the docker exec command:

```bash
docker compose exec -T -e PYTHONPATH=/app backend python /app/scripts/seed_demo_data.py --allow-production
```

## Issue C — CI Build Integrity Gate

### Context

CTO mandated a systemic fix to prevent malformed Docker images from being deployed.

### Implementation

Added a verification step to `.github/workflows/deploy-staging.yml` that runs **after** Docker build but **before** deployment:

```yaml
- name: Build Integrity Gate (Verify Scripts Exist)
  run: |
    IMAGE="${{ steps.meta.outputs.tags }}"
    echo "Verifying critical files in $IMAGE..."

    # Verify seed_demo_data.py exists
    echo "Checking /app/scripts/seed_demo_data.py..."
    docker run --rm $IMAGE ls -la /app/scripts/seed_demo_data.py

    # Verify create_wholesaler.py exists
    echo "Checking /app/scripts/create_wholesaler.py..."
    docker run --rm $IMAGE ls -la /app/scripts/create_wholesaler.py

    # Verify onboard_tenant.py exists
    echo "Checking /app/scripts/onboard_tenant.py..."
    docker run --rm $IMAGE ls -la /app/scripts/onboard_tenant.py

    echo "✅ Build integrity gate passed - all critical scripts verified"
```

### Behavior

- If any critical file is missing → `ls` returns non-zero → **CI fails**
- Prevents malformed images from reaching staging/production
