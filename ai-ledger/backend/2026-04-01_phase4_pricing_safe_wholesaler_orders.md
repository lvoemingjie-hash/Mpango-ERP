Problem StatementThe wholesaler `POST /api/v1/orders` endpoint trusted client-supplied `unit_price` in the request body. This violated Phase 3's pricing authority principle: prices must be server-resolved from `retailer_prices`, never from the frontend. A wholesaler user (or any HTTP client) could inject arbitrary prices into orders.The retailer-facing `POST /api/v1/client/orders` already enforced server-resolved pricing correctly (Phase 3). The wholesaler path needed the same treatment.## 2.
