## 适配内容总结

### P0-1: 订单列表显示 `retailer_name` (无需修改)
- 之前前端已经在 `types/order.ts` 中定义了 `retailer_name: string | null` 并在 UI 中渲染。
- 后端修复此字段回填后，前端直接受益，无需额外修改代码。

### P0-2: 客户 CRM 列表适配
- **服务层 (`services/retailerService.ts`)**:
  - 新增 `RetailerWithBinding` 和 `RetailerListData` 接口。
  - 新增 `getAll()` 和 `getById()` 调用。
- **页面 (`pages/retailers/RetailerListPage.tsx`)**:
  - 切换服务调用由 `getBindings` 至 `getAll(page, size)`。
  - 增加 `<Pagination />` 组件处理分页。
  - 表格数据结构解构调整为 `{ retailer, binding_status, bound_at }`。

### P1-3: Payments 独立查询页面
- **服务层 (`services/paymentService.ts`)**:
  - 新建 `paymentService.ts`。
  - 定义 `PaymentData`、`PaymentListData`。
  - 暴露 `getAll(page, size)` 和 `getById(id)`。
- **页面 (`pages/finance/PaymentListPage.tsx`)**:
  - 新建 Payments 列表页面，展示付款记录详情及状态（交易单号、金额、类型）。
  - 集成 `<Pagination />`。
- **路由 & 侧边栏**:
  - `Sidebar.tsx`: 新增 `Payments` 导航项，图标为 `CreditCardIcon`。
  - `AppRouter.tsx`: 注册 `/payments` 路由。

### P1-4: 库存手动调整功能及库存日志页面
- **服务层 (`services/inventoryService.ts`)**:
  - 新增 `MovementLogEntry`、`MovementLogListData`、`InventoryAdjustRequest` 接口。
  - 新增 `adjustStock(data)` 与 `getLogs(page, size)` 调用。
- **页面 (`pages/inventory/InventoryAdjustModal.tsx`)** (新建):
  - 新增弹窗，使用 React Hook Form + Zod 校验（校验 `sku_code`, `quantity`, `reason`）。
  - 处理负库存/库存不足的 409 异常并在表单层展示友好提示。
- **页面 (`pages/inventory/InventoryPage.tsx`)**:
  - 引入 `InventoryAdjustModal` 弹窗。
  - 每行 SKU 列表添加 `Adjust Stock` 按钮（受 `inventory:update` 权限控制）。
  - 顶部动作栏新增 `View Logs` 入口。
- **页面 (`pages/inventory/InventoryLogPage.tsx`)** (新建):
  - 展示库存变动流水日志（包含变动类型、变动前后的库存对比以及关联原因）。
  - 集成分页处理。
- **路由 (`router/AppRouter.tsx`)**:
  - 注册 `/inventory/logs` 路由。
