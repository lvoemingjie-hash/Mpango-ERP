## 产品边界

- 申报服务在首次持久化前，依据订单已保存币种验证原始金额精度；复用原定点金额合同，不将非法小数先舍入再接受，不修改 canonical、money 算法或模型/迁移。
- live auth store 用会话代际和认证意图序号共同归属。公共 AuthStore DTO 与持久化字段保持原合同，私有归属不成为服务端权限或 HTTP payload。
- Owner 登录、零售登录和工作区选择，将归属贯穿每个异步后续、store 写入、导航及异常处理；同代际的新意图也会替代旧意图。
- 当前有效零售登录失败经集中动作清理并推进代际，保留本次 portal，失效迟到 refresh 和待重试队列；旧请求不得污染新会话。无效 portal/表单不发请求、不清理合法会话。
- OrderList 的收款历史和 collect fallback 两处入口在成功/失败后检查原代际，旧结果不能对新会话提示旧订单、继续历史请求或打开 modal。当前业务错误提示仍保留。
- 显式 Authorization、公用 opt-out、中性401、pending workspace 身份、同代际单 refresh、原权限及金额断言均保留。未覆盖调用者仍需独立按影响审核，不声称全前端安全闭合。
