# Order again

Open your historical order and select **Order again**. The page shows all its
historical lines in historical display order, their old prices and the current
sales units and prices.

1. Review each line. Keep a verified original unit, explicitly remove a line,
   or choose a replacement from the existing available product catalogue.
   Replacement quantities can be changed before reviewing the quote.
2. Resolve unavailable lines. An inactive product, missing price, unverified
   historical identity or changed package cannot be copied automatically.
   Removed lines remain visible with their recorded decision.
3. Select **Review server quote**. Check the complete current lines and total.
   A historical price difference is shown only when the currencies are known
   and comparable.
4. Select **Accept these prices and create draft**. This creates a separate
   draft with a link to the historical order. The historical order and its
   payments remain unchanged.

A stock warning means the supplier must check the full requested quantity.
Saving the draft does not reserve stock or confirm the order. If availability
is insufficient at confirmation, the existing confirmation rules refuse it.

If prices change after review, read the refreshed lines and accept again. If
the result is unknown, use **Retry same accepted submission**. The page retains
your accepted choices and original request key through a reload in the same
browser tab so that retry retrieves the same draft.

The new draft detail displays its historical source. Historical orders can be
used for later independent purchases; each explicit new purchase has its own
accepted quote and request key.

To review another quote for this reorder draft, select **Cancel this draft to
order again** and confirm. This cancels only the new draft and leaves the
historical order unchanged. After cancellation is confirmed, select **Order
again from historical order** to review a fresh quote. Nothing is created or
opened automatically. If cancellation fails or its result is unknown, check the
draft's status before continuing; the follow-up link remains unavailable.
Ordinary S1 drafts still offer **Review new quote and replace this draft**.
