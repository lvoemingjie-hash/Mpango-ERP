# S1-2 CI Gate Implementation

## Date
2026-02-03

## Task
Implement CI/CD pipeline gates for S1-2 Auth Strategy Refactor to enforce architecture changes and prevent regression.

## Background
The Backend AI completed Task S1-2 which refactored authentication into a Strategy Pattern:
- `MPANGO_ENV` is now the single environment control variable
- `MPANGO_TEST_MODE` has been deprecated and removed
- `auth/factory.py` is the only location that branches on environment
- `MockAuthStrategy` is only loaded in test environment
- `JwtAuthStrategy` is used in production and as default

## CI Gates Implemented

### 1. Static Analysis Gate (The "Grep" Check)

**Purpose:** Prevent re-introduction of deprecated `MPANGO_TEST_MODE` variable.

**Implementation:**
- Workflow: `.github/workflows/s1-2-ci-gate.yml`
- Job: `s1-2-static-analysis`
- Command: `grep -r "MPANGO_TEST_MODE"` across Python, YAML, shell, env, and Dockerfile files
- Exclusions: `node_modules/`, `venv/`, `.venv/`, `dist/`, `build/`, `.git/`, `ai-ledger/`, and the CI file itself

**Behavior:**
- ❌ **FAIL** if `MPANGO_TEST_MODE` is found in any source file
- ✅ **PASS** if no references exist (excluding documentation)

**Example Failure:**
```
❌ FAIL: MPANGO_TEST_MODE detected in codebase!

Found in the following files:
backend/api/middleware/auth.py:    if os.getenv("MPANGO_TEST_MODE"):
backend/api/dependencies.py:        MPANGO_TEST_MODE = True

This variable has been deprecated. Use MPANGO_ENV instead.
See: ai-ledger/backend/2026-02-03_s1-2_auth_strategy_refactor.md
```

### 2. Test Environment Verification

**Purpose:** Ensure test suite passes with `MPANGO_ENV=test` proving MockAuthStrategy works correctly.

**Implementation:**
- Workflow: `.github/workflows/s1-2-ci-gate.yml`
- Job: `s1-2-test-verification`
- Environment: `MPANGO_ENV=test`
- Services: PostgreSQL 15, Redis 7

**Steps:**
1. Install dependencies with Poetry
2. Run auth strategy tests: `tests/test_auth_bypass.py`, `tests/test_test_mode_auth_bypass.py`
3. Verify MockAuthStrategy is loaded for test environment

**Verified Behaviors:**
- ✅ Requests pass through without JWT in test mode
- ✅ RBAC permission checks are still enforced
- ✅ MockAuthStrategy is correctly injected

### 3. Production Safety Check

**Purpose:** Ensure MockAuthStrategy is never loaded in production and JwtAuthStrategy is properly used.

**Implementation:**
- Workflow: `.github/workflows/s1-2-ci-gate.yml`
- Job: `s1-2-production-safety`

**Checks:**

#### 3a. Direct Import Check
Verifies no production file directly imports from `auth.strategies.mock`:
```bash
PROD_FILES=("backend/main.py" "backend/api/dependencies.py" "backend/api/app.py")
grep -q "from auth.strategies.mock import\|import auth.strategies.mock"
```

#### 3b. Production Strategy Verification
```python
import os
os.environ['MPANGO_ENV'] = 'production'
from auth.factory import get_auth_strategy
from auth.strategies.jwt import JwtAuthStrategy
strategy = get_auth_strategy()
assert isinstance(strategy, JwtAuthStrategy)
```

#### 3c. Default Strategy Verification
```python
import os
del os.environ['MPANGO_ENV']  # Ensure no env var
from auth.factory import get_auth_strategy
from auth.strategies.jwt import JwtAuthStrategy
strategy = get_auth_strategy()
assert isinstance(strategy, JwtAuthStrategy)
```

#### 3d. Single Branching Point Check
Verifies `MPANGO_ENV` is only used in `auth/factory.py`:
```bash
grep -r "MPANGO_ENV" . --include="*.py" --exclude="*/factory.py"
```

## Rollback Instructions

If the CI gates cause issues:

1. **Temporarily disable a gate:**
   - Edit `.github/workflows/s1-2-ci-gate.yml`
   - Add `continue-on-error: true` to the problematic job
   - Or comment out the specific check step

2. **Emergency bypass:**
   - Add the `bypass-s1-2-gate` label to the PR (if configured)
   - Or use GitHub's "bypass rules" with admin privileges

3. **Fix and re-enable:**
   - Address the root cause
   - Remove the bypass
   - Re-run the workflow
