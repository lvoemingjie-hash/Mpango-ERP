## 3. Classification (670 = 670, gap = 0)

### 3.1 TEST_FIXTURE_ISOLATION (611)

**Root cause:** `RuntimeError: "There is no current event loop in thread 'MainThread'"` — async fixture/session configuration issue. These tests pass individually when the event loop is properly scoped. The full-suite failure is caused by pytest's asyncio event loop policy not being configured for the test session, causing a shared event loop to be garbage-collected between test modules.

**Fix path:** Adjust test configuration (`asyncio_mode`, `event_loop_policy`) in `conftest.py` or `pytest.ini` — no product code changes required.

### 3.2 CONFIRMED_MIGRATION_GAP (31)

**Breakdown:**
- **18 errors:** `relation "users" does not exist` in tenant schemas `t_s3b`/`t_s3c` that use public-schema tables — these tenants were created before the user migration and lack the `users` table in their tenant schema.
- **13 failures:** `retailer_prices` schema contract violations in `t_dev` — constraint names, column nullability, or index names don't match migration 017's expected contract.

**Fix path:** New Alembic migration to reconcile existing tenant schemas to current DDL contract.

**Root cause:** `"reporting_role does not exist"` during bootstrap/reconcile. Migration `011_s6_p_reporting_role` creates the reporting role, but it is not propagated correctly to all tenant schemas during reconcile operations.

**Fix path:** Ensure reporting role creation is idempotent and included in the reconcile script.

**Fix path:** Update test assertions to match current ORM model structure and route configuration.
