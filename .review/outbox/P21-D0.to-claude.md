# SHADOW ONLY

**Objective:** Validate Goose as a low-privilege middleman by reading this task, generating a Claude handoff packet, and writing an audit log without touching runtime code or dispatching automatically.

**Scope:** Review Bus protocol only. Initiate a Goose shadow handoff.

**Forbidden Changes:** The process explicitly forbids any changes to backend, frontend, documentation, package files, lockfiles, or any operational filesystem commands outside of the designated review directories.

**Validation Gates:** Validation requires that the outbox file is generated, the audit log exists and records all activities (task_id, timestamps, files read/written, shadow mode statement), and no runtime code was touched or changes were attempted.

**Stop Conditions:** Stopping conditions include unparsable task files, attempts to write outside `.review`, attempting to edit runtime code, attempting to merge/push, and failure to produce the required audit trail.

**Result Report Format:** The final result requires a structured handoff packet for the worker (Claude) and a detailed immutable audit log for tracking the shadow execution.

**Next Action:** Explicitly require review and approval from Codex/user before any real action is taken.
