# Sales / Stock 同步 CSV 下载

Sales（订单列表）的 CSV 按钮导出当前授权租户的全部订单，不跟随列表筛选或分页；Stock（库存列表）的 CSV 按钮导出当前租户的库存。订单状态筛选只是 API 的可选能力，页面按钮不传递该筛选；API 会拒绝不支持或重复的筛选，不会静默扩大下载范围。

下载要求已登录、选定租户并具有 `exports:create` 权限。页面浏览权限不等于导出权限；服务器会再次检查权限与租户上下文。文件包含业务数据，请仅交给有权查看的人员。

## Excel 导入

文件使用 UTF-8 编码、一个开头 BOM 和逗号分隔。推荐按以下步骤打开：

1. 在 Excel 中选择“数据 → 从文本/CSV”，选择下载文件。
2. 明确选择 UTF-8 编码及逗号分隔符，不使用系统区域设置猜测分隔符。
3. 在加载前将 SKU、长 ID、带前导零的代码列设置为“文本”，避免截断、科学计数法或丢失前导零。
4. 先检查预览中的列数、产品名称、币种及金额，再加载。

逗号、分号、双引号和字段内换行由 CSV writer 引用与转义。在上述逗号导入合同中，它们不会被拆成额外单元格。订单备注沿用现有导出行为，将换行显示为空格；库存文本可保留字段内换行。

## 公式防护与使用边界

以半角或全角 `= + - @`（`＝ ＋ － ＠`）开头的文本，包括前导空白、BOM 或控制字符，会在导出展示值前加单引号；制表符、回车或换行开头的文本也保留既有防护。判别时只转换字符副本，不改写原字形，也不修改数据库业务值。可信数值类型的负数仍输出为数值，普通 Unicode 文本保持原值。

单引号可能显示在导入后的文本中。这是安全展示文件，不是可无损机器回导的业务交换协议。直接双击、使用其他区域分隔符、保存后重新打开，以及任何具体 Excel 版本是否执行公式，都不属于本轮已验证保证；有疑问时请按文本导入并检查预览。Python CSV 解析测试不等于真实 Excel 验收。

同步 CSV 不包含发票 JSON，也不替代异步 XLSX 导出。下载失败时应检查服务器返回的错误，不使用错误响应体作为 CSV 保存。
