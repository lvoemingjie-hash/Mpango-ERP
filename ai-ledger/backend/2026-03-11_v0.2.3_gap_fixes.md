## P0-1: Orders `retailer_name` 回填

**问题**: 订单列表 / 详情中 `retailer_name` 始终为 `null`，前端无法看到客户名。

**根因**: `order_to_schema()` 硬编码 `retailer_name=None`，未从 `public.retailers` 表查询。

**修复**:
- `backend/crud/order.py` — 新增 `batch_retailer_names(db, retailer_ids)` 函数
  - 使用 `SELECT id, name FROM public.retailers WHERE id = ANY(:ids)` 批量查询
  - 返回 `Dict[str, str]`，避免 N+1
- `backend/api/v1/orders.py` — 修改：
  - `order_to_schema()` 新增 `retailer_name` 参数
  - `list_orders()` 批量预取 retailer names 后传入
  - `get_order()` 同样预取

**影响文件**:
- `backend/crud/order.py`
- `backend/api/v1/orders.py`

## P1-4: Inventory Adjustment & Movement Log

**问题**: 库存仅可读，缺少手动调整（盘点 / 损耗 / 纠错）和流水日志。

**修复**:

### 新建模型
- `backend/models/inventory_movement.py` — `InventoryMovement` 模型
  - 字段: `sku_id`, `movement_type`, `quantity`(带符号), `quantity_before`, `quantity_after`, `reason`, `reference_type`, `reference_id`
  - 索引: `sku_id`, `created_at`

### Schema
- `backend/schemas/inventory.py` — 新增：
  - `InventoryAdjustRequest` — sku_code + quantity(±) + reason
  - `InventoryAdjustResponse` — before / after / adjustment / reason
  - `MovementLogEntry` — 单条日志
  - `MovementLogListData` — 分页日志

### Service
- `backend/services/inventory_service.py` — 新增：
  - `adjust_stock()` — SELECT FOR UPDATE + 修改 quantity_on_hand + 写入 movement 日志
  - `list_movements()` — JOIN SKU 的分页查询

### API
- `backend/api/v1/inventory.py` — 新增：
  - `POST /inventory/adjust` — 手动调整，权限 `inventory:update`
  - `GET /inventory/logs` — 流水日志，权限 `inventory:read`

### DDL
- `backend/scripts/seed_demo_data.py` — `_bootstrap_tenant_schema()` 中新增 `inventory_movements` 表 DDL

**影响文件**:
- `backend/models/inventory_movement.py` (NEW)
- `backend/schemas/inventory.py`
- `backend/services/inventory_service.py`
